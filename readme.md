# Agent Sessions

Browse OMP and Claude Code sessions. A file opened from a session uses the comment view.

Source lives in this repository. Layout notes for later changes are in `AGENTS.md`. Changes since 1.2.5 are in `changelog.md`.

## Install

```bash
npm install
npm run package
```

In Cursor, open the command palette, choose **Extensions: Install from VSIX…**, and pick the generated `agent-sessions-*.vsix`. If `local.agent-sessions` is already installed, installing the new package replaces it.
